# Animation Component Design Prompts

## 🎬 Hero Section
```
Design a hero section for a stickman animation website with:
- Large animated heading with text effects
- Floating animation elements (sparkles, stars, geometric shapes)
- Interactive background with mouse tracking
- Clear call-to-action buttons
- Stats display with animated counters
- Smooth scroll indicator
- Use Framer Motion for animations
- Tailwind CSS for styling
- Mobile-responsive design
```

## 🎭 Animation Showcase
```
Create an animation showcase component featuring:
- Grid of animation cards with hover effects
- Play button overlays with smooth transitions
- Category badges and rating displays
- Like/share functionality with micro-animations
- Filtering tabs for different animation types
- Load more button with loading states
- 3D card effects on hover
- Smooth staggered animations on scroll
```

## 🎨 Portfolio Grid
```
Design a portfolio grid component with:
- Masonry-style layout for animation projects
- Hover effects with project details overlay
- Filtering system (category, duration, style)
- Search functionality with autocomplete
- Project tags and metadata display
- Smooth transitions between filter states
- Lazy loading for performance
- Accessibility features (ARIA labels, keyboard navigation)
```

## 📱 Interactive Elements
```
Create interactive UI elements for animation website:
- Animated navigation menu with smooth transitions
- Floating action buttons with particle effects
- Progress indicators for animation loading
- Interactive tooltips with smooth animations
- Modal dialogs with backdrop blur effects
- Form inputs with animated focus states
- Button hover effects with scale and shadow changes
```

## 🚀 Performance Optimized
```
Design performance-optimized components:
- Lazy-loaded image galleries
- Intersection Observer for scroll animations
- Debounced search inputs
- Virtual scrolling for large lists
- Optimized animation loops
- Reduced motion support for accessibility
- Efficient re-renders with React.memo
- Bundle splitting for code optimization
```

## 🎯 Best Practices
- Use CSS transforms instead of layout properties for animations
- Implement proper loading states and skeleton screens
- Ensure 60fps animations with requestAnimationFrame
- Add proper error boundaries and fallbacks
- Use semantic HTML for accessibility
- Implement proper focus management
- Add keyboard navigation support
- Include proper ARIA labels and descriptions
